# Tisane Dictionaries

This contains various dictionaries which can be useful when using [Tisane](https://github.com/beckbria/tisane/) in puzzle hunts or other events.

## Wikipedia

A dictionary of Wikipedia article titles compiles to more than 200MB as of 2026. This is larger than Github permits, so a tool to generate your own Wikipedia dictionary from dumps is provided in the `wikipedia/` directory.

## WordNet

A tool is provided to generate dictionaries from the [Open English WordNet](https://en-word.net/). When using it please mind their license.
